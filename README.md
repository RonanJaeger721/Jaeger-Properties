# Jaeger Properties

A premium property design concept by Jaeger Media, built with Next.js App Router, TypeScript, Tailwind CSS and GSAP ScrollTrigger.

```sh
npm install
npm run dev
```

Open http://localhost:3000. Verify with `npm run typecheck` and `npm run build`.

Home, buy, rent, property details, developments, The Residence, finder, about, contact, saved homes and local management are implemented. All listings, pricing and specifications are illustrative. No properties are genuinely available.

Enquiries, listings and photos persist in browser IndexedDB; favourites use localStorage. `/admin` is an open local demonstration, not a secured shared CMS. No real viewing is booked or property enquiry sent externally. The footer has a separate genuine Jaeger Media business WhatsApp handoff.

See [implementation](docs/implementation.md), [image sources](docs/image-sources.json) and [verification](docs/verification.md).
